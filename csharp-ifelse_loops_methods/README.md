# C# - If/Else, Loops, and Methods

This project contains introductory C# exercises covering conditional
statements, loops, and methods.

## Task 0: Positive or Negative

`0-positive_or_negative` generates a random signed integer and reports whether
the value is positive, zero, or negative.

Run the task with:

```sh
cd 0-positive_or_negative
dotnet run
```

## Task 1: The Last Digit

`1-last_digit` generates a random signed integer, extracts its last digit, and
reports whether that digit is greater than 5, is 0, or is less than 6 and not 0.

Run the task with:

```sh
cd 1-last_digit
dotnet run
```

## Task 2: Print the Alphabet

`2-print_alphabet` prints the lowercase English alphabet using one loop and one
call to `Console.Write`, without adding a trailing newline.

Run the task with:

```sh
cd 2-print_alphabet
dotnet run
```
