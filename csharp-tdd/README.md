# C# - Test Driven Development

Each task is a .NET solution with a class library (`netstandard2.0`) and an NUnit test library (`netcoreapp2.1`). Tests were written before the code.

| Task | Method |
| --- | --- |
| 0-add | `MyMath.Operations.Add` |
| 1-divide | `MyMath.Matrix.Divide` |
| 2-max_int | `MyMath.Operations.Max` |
| 3-palindrome | `Text.Str.IsPalindrome` |
| 4-unique | `Text.Str.UniqueChar` |
| 5-camelcase | `Text.Str.CamelCase` |

Run the tests from a task directory with `dotnet test`.
